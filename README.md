### Régimen de aprobación

Se deben aprobar dos exámenes parciales. Habrá dos fechas de recuperación al finalizar el cuatrimestre, una para cada examen. Para poder ser incluido en las actas de trabajos prácticos es necesario haberse inscripto, mediante el [sistema de inscripciones de la facultad](https://inscripciones.exactas.uba.ar/exactas/)

### Correlatividades

Para cursar esta materia se deberán tener aprobados los Trabajos Prácticos de Cálculo Avanzado y los Exámenes Finales de Análisis II y Álgebra Lineal. \
